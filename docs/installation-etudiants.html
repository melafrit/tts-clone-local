Installation ultra guidée (Étudiants)

Objectif : installer et lancer une interface web locale pour cloner ta propre voix et générer de la synthèse multilingue avec XTTS v2 (Coqui TTS), sur Windows.

Auteur du projet : Mohamed Amine EL AFRIT — www.mohamedelafrit.com

1) Ce que tu vas obtenir

  • Un environnement Python propre et isolé (venv)
  • PyTorch installé (CPU ou GPU)
  • Coqui TTS + Gradio
  • Une interface web locale sur http://127.0.0.1:7860

2) Prérequis

  • Windows 10/11 64 bits
  • Python 3.11.x recommandé
  • RAM : 16 Go minimum (32 Go conseillé)
  • GPU NVIDIA 8–12 Go VRAM conseillé (sinon CPU ok)
Conseil Évite Python 3.12/3.13/3.14 pour ce projet si tu veux minimiser les erreurs de dépendances.

3) Installer Python 3.11

  1. Télécharge Python 3.11 depuis le site officiel.
  2. À l’installation, coche Add Python to PATH.
  3. Vérifie :
python --version
pip --version

4) Créer le dossier du projet

mkdir C:\TTS
cd C:\TTS

5) Créer et activer un environnement virtuel

python -m venv venv
.\venv\Scripts\Activate.ps1
Si blocage PowerShell 
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

6) Mettre à jour pip

python -m pip install --upgrade pip

7) Installer PyTorch

7.1 Avec GPU NVIDIA (recommandé)

pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118

7.2 En CPU

pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu

7.3 Vérifier la détection GPU

python -c "import torch; print('CUDA available:', torch.cuda.is_available()); print('Device:', torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU only')"

8) Installer les dépendances de l’interface

pip install gradio
pip install TTS

9) Ajouter le script

Place xtts_web_ui_pro.py dans C:\TTS. 

C:\TTS\
  ├─ venv\
  ├─ xtts_web_ui_pro.py
  └─ outputs\   (créé automatiquement)

10) Lancer l’interface

cd C:\TTS
.\venv\Scripts\Activate.ps1
python xtts_web_ui_pro.py
Résultat attendu
Le navigateur s’ouvre sur http://127.0.0.1:7860. Sinon, ouvre l’URL manuellement.

11) Préparer ta voix (WAV)

  • Commence avec 30–60 secondes.
  • Idéal : 1–2 minutes propres.
  • Format recommandé : WAV 44.1 kHz ou 48 kHz, mono.
  • Environnement silencieux, distance micro stable.
Important Clone uniquement ta propre voix ou une voix explicitement autorisée.

12) Réglages simples (conseillés)

  • Similarité : 80–90
  • Style : 20–35 (cours/narration)
  • Stabilité : 50–70
  • Vitesse : 103–108

13) Dépannage rapide

  • Si c’est lent : normal en CPU.
  • Si erreur de dépendances : réinstalle dans le venv.
pip install --upgrade pip
pip install gradio TTS
