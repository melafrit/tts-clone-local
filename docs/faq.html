FAQ — Questions fréquentes

Réponses courtes, concrètes et orientées usage réel pour l’interface locale de clonage vocal basée sur XTTS v2.

Auteur : Mohamed Amine EL AFRIT — www.mohamedelafrit.com

Général

À quoi sert exactement ce projet ?
À lancer une interface web locale sur Windows pour générer de la voix à partir d’un texte et d’un fichier audio de référence, avec XTTS v2. L’objectif est pédagogique et pratique : comprendre les réglages, tester la qualité, et produire des audios en local.
Est-ce un entraînement complet d’un nouveau modèle ?
Non. On utilise un modèle pré-entraîné (XTTS v2) et on réalise un clonage par référence audio (voice cloning par prompt/conditionnement), ce qui est bien plus léger qu’un fine-tuning.
CPU ou GPU : qu’est-ce que ça change ?
Le rendu final peut être similaire, mais le temps de génération est bien plus rapide avec une GPU NVIDIA.

Installation

Quelle version de Python dois-je utiliser ?
Python 3.11.x est recommandé pour éviter les conflits de dépendances.
J’ai une erreur à l’activation du venv dans PowerShell
Exécute une fois : 
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
Puis : 
.\venv\Scripts\Activate.ps1
PyTorch ne détecte pas ma GPU
Vérifie : 
python -c "import torch; print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU only')"
Si besoin, réinstalle PyTorch GPU : 
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118

Qualité audio et clonage

Quelle durée de voix de référence faut-il ?
Bon point de départ
30–60 secondes propres.

Recommandé
1–2 minutes, enregistrées sans bruit ni réverbération.
Quel format de fichier est le meilleur ?
WAV recommandé, 44.1 kHz ou 48 kHz, mono.
Pourquoi ma voix clonée semble “différente” ?
Causes fréquentes :
  • WAV trop court ou bruité
  • Texte demandé dans une langue très différente de la voix d’origine
  • Similarité trop basse
  • Température / expressivité trop élevée
Quels réglages simples recommandez-vous ?
Pour une voix de cours claire et stable :
  • Similarité : 80–90
  • Style : 20–35
  • Stabilité : 50–70
  • Vitesse : 103–108

Usage responsable

Puis-je cloner la voix de quelqu’un d’autre ?
Uniquement si tu as une autorisation explicite. L’usage attendu dans ce cadre pédagogique est de cloner ta propre voix.
Dois-je signaler l’usage d’une voix synthétique ?
En contexte public, professionnel ou éducatif, c’est une bonne pratique.
